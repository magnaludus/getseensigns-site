# Get Seen Signs website: build source

The site is a static site generated by Python. The built pages live at the repo root
(index.html, product folders, blog, 404.html, privacy.html, sitemap.xml, robots.txt).
Cloudflare Pages publishes `main` automatically about a minute after every merge, so a merge is the publish step.

## Files

| File | What it holds |
|---|---|
| `src/seo_products.py` | Product page copy, FAQs and the "from" prices (`price=`). `price=None` shows no price and adds no Offer (feather flags). |
| `src/seo_pages.py` | Local landing pages, blog posts and the gameday page. |
| `src/site-src-index.tpl.html` | Home page body (between `<main>` and `</main>`). |
| `src/site-src-pages.py` | Builds every HTML page, sitemap.xml, robots.txt and 404.html. Shared head, nav, footer and the shipping schema (`shipping_details`, `TRANSIT`, `RETURNS`). |
| `assets/style.css` | CSS source. It is inlined into every page at build time, so a style change needs a rebuild. |
| `assets/` | Images, fonts (Barlow, OFL) and brand files, already built. |

## Build

```
pip install pillow
git pull origin main
python3 src/site-src-pages.py
```

Run it from anywhere; paths are relative to the repo root. Output is written to the repo root.
Then check `git diff`: only the pages you meant to change should differ.

## Checklist before every PR

- Keep the canonical tag (`https://getseensignsco.com/<slug>/`, https, bare domain, trailing slash) on every page.
- Keep `shippingDetails` (free US shipping) and `hasMerchantReturnPolicy` (MerchantReturnNotPermitted) on every Offer.
- Site prices must match the live Etsy prices. Change Etsy first, then `seo_products.py`, then rebuild.
- No trademarks: keep the line that buyers own the artwork they send and we don't print team names or logos.
- Keep the sitemap entry and breadcrumb for every page. Keep `privacy.html` as the file name (it serves at /privacy).
- Never hand-edit a built page; the next rebuild overwrites it. Edit `src/` and rebuild.
- Nothing private goes in this repo: no costs, margins, supplier names or quotes, passwords, tokens or account details.

## Publishing

Work on a branch, commit the source and the rebuilt pages together, and open a pull request against `main`.
Never push to `main` directly. Merge (squash) only after Scott says yes in chat.
